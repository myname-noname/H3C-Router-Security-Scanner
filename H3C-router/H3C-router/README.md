# H3C Router Security Scanner v1.0 — 路由器配置泄露检测工具

## 一、工具简介

H3C Router Security Scanner 是一款针对 H3C 系列路由器（如 ER8300G2-X）的配置泄露检测工具。利用路径穿越漏洞，可获取路由器配置文件，从中提取 Telnet/Web 管理密码等敏感信息，帮助管理员及时发现安全风险。

## 二、漏洞原理

H3C ER8300G2-X 等路由器存在路径穿越漏洞，攻击者可通过以下 URL 绕过权限验证，直接下载配置文件：

```
/userLogin.asp/../actionpolicy_status/../ER8300G2-X.cfg
```

配置文件中包含以下敏感信息：

| 字段 | 说明 |
|------|------|
| `admpwd` | Web 管理登录密码（@webadmin 段） |
| `vtypasswd` | Telnet 远程登录密码（@base 段） |
| `model` | 设备型号 |
| `version` | 固件版本 |
| NTP / DHCP | 网络配置信息 |

## 三、功能特性

- [x] H3C 设备指纹识别（基于 finger.json 指纹库）
- [x] 路径穿越配置泄露检测
- [x] 配置文件敏感信息自动提取（Web 密码、Telnet 密码、设备型号等）
- [x] 弱口令验证
- [x] 多线程并发扫描（可自定义线程数 1-100）
- [x] 端口预检（跳过关闭端口，加速扫描）
- [x] 结果表格排序（点击"状态"列切换脆弱优先 / 原始顺序）
- [x] 结果导出（CSV / TXT 格式）
- [x] 暗色安全工具风格 UI（PyQt5）
- [x] 支持批量目标扫描（IP、CIDR、范围、TXT 文件导入）

## 六、使用方法

### 1. 启动程序

```bash
python main.py
```

### 2. 配置扫描参数

- **扫描目标**：输入 IP 地址 / 域名 / CIDR / 范围，逗号分隔；或点击"选择 TXT"从文件加载（每行一个 IP）
- **扫描端口**：默认 `8081,10001,8090`（H3C 设备常用端口），可修改为其他端口，英文逗号分隔
- **并发线程**：建议 10-50，根据网络状况调整
- **超时（秒）**：建议 2 秒

### 3. 开始扫描

点击 **"开始扫描"** 按钮，实时查看进度和日志；点击 **"停止"** 可随时终止扫描。

### 4. 查看结果

扫描结果以表格形式展示，包含：

| 列名 | 说明 |
|------|------|
| 状态 | 脆弱 ✓ / 安全 ✗ |
| 目标 | 目标 IP 地址 |
| 端口 | 目标端口 |
| 指纹 | 识别的设备指纹 |
| 漏洞类型 | 漏洞分类 |
| 敏感信息 | Web 密码、Telnet 密码、设备型号等 |
| 详情 | 利用路径等详细信息 |

点击 **"状态"** 列表头可切换排序模式：
- **脆弱优先**：所有漏洞结果排在前面
- **原始顺序**：恢复扫描时的排列顺序

### 5. 导出结果

点击 **"导出 CSV"** 或 **"导出 TXT"** 保存扫描报告。

## 七、目标格式说明

支持以下格式（可在输入框中混用，逗号分隔）：

| 格式 | 示例 |
|------|------|
| 单个 IP | `192.168.1.1` |
| 多个 IP | `192.168.1.1,192.168.1.2` |
| CIDR 网段 | `192.168.1.0/24` |
| IP 范围 | `192.168.1.1-100` |
| 域名 | `example.com` |
| TXT 文件导入 | 点击"选择 TXT"按钮 |

> **注意：** 端口请在"扫描端口"输入框中单独指定，不支持在 IP 后加 `:端口` 格式。

## 八、扫描结果说明

- **脆弱（✓ 脆弱）**：目标存在配置泄露漏洞，已获取配置文件
- **安全（✗ 安全）**：目标未发现配置泄露漏洞

### 敏感信息字段

| 字段 | 说明 |
|------|------|
| `admpwd` | Web 管理密码（@webadmin 段） |
| `vtypasswd` | Telnet 登录密码（@base 段） |
| `admpwdpromt` | 密码找回验证信息 |
| `model` | 设备型号 |
| `version` | 固件版本 |
| `passwd` | 其他密码字段 |

## 九、注意事项

1. **本工具仅用于授权的安全检测，请勿用于非法用途！**
2. 扫描前请确保已获得目标系统所有者的明确授权。
3. 部分 H3C 设备可能已修复该漏洞，扫描结果仅供参考。
4. 扫描过程中请勿关闭程序，建议等待扫描完成。
5. 如需关闭窗口，程序会提示确认（扫描进行中时）。
